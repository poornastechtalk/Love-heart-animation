# ❤️ Python Love Heart Animation

A creative Python Turtle animation that builds a beautiful heart using expressions of "I Love You" in 20 different languages.

## ✨ Project Overview

This project transforms meaningful words into an animated heart using Python programming. Each phrase gradually appears to form a heart-shaped design, followed by a beautiful shimmering effect.

## 🚀 Features

- ❤️ Animated heart formation using text.
- 🌍 "I Love You" expressions in 20 languages.
- 🎨 Beautiful crimson and red colour effects.
- ✨ Smooth text reveal animation.
- 💫 Glowing and shimmering visual effects.
- 🖥️ 800 × 800 animation window.

## 🛠️ Technologies Used

- Python
- Turtle Graphics
- Tkinter
- Math Module
- Random Module

## 📋 Requirements

- Python 3
- Tkinter support

No additional pip packages are required.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python love_heart.py
```

4. Enjoy the animated heart!
